# OrangeFox Recovery for Samsung Galaxy A7 2018 (a7y18lte)

Maintainer: eyge102

An unofficial build of OrangeFox Recovery Project for the Samsung Galaxy A7 2018.

---

## Device Specifications

| Feature | Specification |
| :--- | :--- |
| Device Model | Samsung Galaxy A7 2018 (SM-A750F / SM-A750FN / SM-A750G) |
| Codename | a7y18lte |
| SoC | Samsung Exynos 7885 Octa |
| Kernel | Linux 4.4.x |
| Display | 1080 x 2220 |
| Base Android | Android 9.0 (Omni 9.0) |

---

## Features

- Material Design UI with customizable color accents and themes
- Flashlight support
- Boot splash logo customization support
- Built-in file manager, terminal and text editor
- Magisk and Magiskboot integration
- Full partition backup and restore (System, Vendor, Boot, Recovery, EFS, Data, Cache)
- MTP, ADB, USB-OTG and SD card support
- Password, PIN and pattern protection

---

## Building From Source

This project compiles automatically via GitHub Actions CI.

To build manually:
1. Fork or clone this repository.
2. Navigate to the Actions tab on GitHub.
3. Run the "Build OrangeFox Recovery" workflow.

Compiled artifacts (recovery image, Odin tar package, and flashable zip) will be available in the workflow run summary and Releases tab.
